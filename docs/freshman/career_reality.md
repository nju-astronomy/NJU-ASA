# 兴趣之外：天文作为职业的另一面
>当“我这辈子只做天文”的最初热情慢慢可能因为成绩、压力等因素而被你重新考虑之后，如果将天文作为职业选择，这条路在时间、精力、生活方式和机会成本上意味着什么？

如果看到这里你对自己是否愿意做天文研究有了进一步的思考，那么恭喜你，你更好地认识了自己！如果你发现你还要再思考思考，那么，有句俗话说的好，爱上一个人很容易，一直爱下去往往很难。为什么网上会充斥着大量对于基础学科专业的劝退贴，可能因为情绪宣泄与个例放大有些夸张，不过一般来说，每一届进入天空院的同学中，未来真正长期从事天文科研的人，可能只有 20% 甚至更少。当然，这并不意味着本科阶段选择天文或物理是错误的决定，其实这样的专业训练依然具有很强的通用价值与竞争力（见[天文之外](../beyond_astro/careers.md)），当然我这里的观点可能主要针对的是天体物理这一方向的情况，实际上如果在天力天测和空间科学方向上，那么可能就不止科研这一条路，因为他们还涉及到了和航空航天相关的领域，包括对于航天器的设计、一些卫星、航天器轨道的计算，每年学院这部分方向的同学会有一些去航天院所工作，甚至去做商业航天的。

但在做出“是否将天文作为职业道路”这一决定之前，对这条路径本身有一个尽量清醒的认识，仍然是必要的。在现在的大环境下，如果你希望未来在天文学界获得一份教职，这条路径意味着：在本科阶段，你需要具备足够突出的能力，支撑你继续进入研究生阶段；若直接申请国外的 PhD，按照目前的竞争态势，你的综合能力很可能需要位于中国大陆天文相关本科生的前 1%。如果选择在国内体系中继续深造，那么在天空院，你大致需要处于前 50% 才具备较为稳妥的保研资格。进入研究生阶段后，科研能力、论文质量、研究方向与导师资源等因素将进一步叠加，你仍需处在同龄人中的前列，才有机会进入一个较好的博士后平台。而博士阶段通常需要 5-6 年，一段博后一般 2-3 年。若希望在南大层次的高校获得教职，现实中往往需要经历两期甚至更多博后，并且是在世界范围内较为顶尖的科研机构之间不断流动。这样的好处在于，可以边科研边环游世界，认识更多的人，与不同的人打交道，体验不同的文化，但一方面就是回过头来看，人生往往已至三十岁出头，居住地频繁更换，这条路是否是你认同的或者承担的，值得认真思考。然后再说说薪资情况，这小部分可能后面会有所修改，博士后实际上已经可以算是一份工作，那么在天空院博后的薪资可能平均下来在税前年薪30w这样，当然对于一些组中比较强的博后，听闻有拿到70w的情况，而往后找教职，天空院的助理教授目前是税前45w左右一年，不知道有没有算上绩效，再往上副教授、教授就可能和人才、基金的评定有一定关系，也和老师们的成果挂钩，不过估计也不会少于45w一年这个数，学校每年都会招聘广告，感兴趣的同学可以看看待遇水平，其他学校的情况有待补充。

此外，对于科研，努力了不一定有回报，不努力肯定没有回报。方向选择、研究环境、机遇本身都会影响，可能在一个课题上投入多年，结果因为一些原因没有产出；也可能因为导师、合作者或外界的压力，遭遇与你能力并不完全匹配的结果，有能力却未必获得理想回报，在科研中并不罕见。因此，如何在科研之外，为自己构建相对稳定、可预期的正反馈来源，往往比想象中更重要。	

**我们的本意绝对不是劝退！**即便最终没有选择继续走在天文科研这条路上，这段经历本身，也是一段非常重要的积累。天文与物理训练教会我们的，远不止天文知识。它塑造的是你面对未知问题时的耐心、拆解复杂问题的能力、在长时间没有答案的情况下仍然推进工作的习惯，以及对“不确定性”的容忍度。这些能力，在科研之外的许多领域——无论是工业界、数据科学、金融、工程、教育，还是完全不同的人生选择中——都具有长期价值。但很多时候，“我喜欢天文”和“我适合以天文研究为主要职业”，并不是同一个问题。（欧阳马霖，天体物理方向，2022级本科生）

Malin上面都说的很有道理，我可以先具体写写每个阶段，大家可能遇到的困难。首先是本科阶段，这个时间段的挑战可以说是最小的。年级前50%能获得推免资格，即便没到50%，也可以考研上岸。我相信如果一位同学能高考考上南大天文，那凭借同样的毅力拼搏大半年，也大概率能考上天文的研究生。由于本科的时候有各式各样的分心事，绝大部分保研的同学，毕业前ads账号都不会开户（没有文章被接收），并且GPA看起来差不多，还不会有特别差距。到了PhD阶段各种落差感就会开始显现，你的同学可能每年能发一篇一作，甚至发Nature Astronomy，毕业时候轻松申到各种fellow，能在国际会议上做contributed talk，而你到第五年才艰难投出第一篇（假设你是直博/硕转博生），会议上的海报也无人问津。虽说文章产出主要靠postdoc阶段，然而PhD没有足够的成果，那也很难找到postdoc。到了下一个阶段，博士后，第一个要适应的是：你在任何语境下都不再是学生了，这是一份工作，如果你的成果让教授或学院不满意，随时就可以把你kick掉，此外，你每隔两三年大概率就要move，如果找到另一半，或者维持另一半的关系很可能是个问题。随后就是找faculty的环节，国外和不少国内学院的教职岗位都逐渐饱和。据说是24年？ 北美的AP岗位只有三个，如果要在NJU这种层次的学校，大致需要10篇APJ一作/通讯（放心，以后要求会更高的）。如果去一般的学校，那里没有单独的天文系，意味着你要跟不同物理专业的人抢饭碗，那里只有三篇文章确实就有机会入职，然而考核要求无法与你的平台对应，此外退还安家费后还要倒贴这种事可能真的会发生。即便最后拿到长聘，学院或者你本人可能会逼着自己申一个一个帽子，一笔笔经费（到那个时候，你可能有了松弛的资本，但或许已经忘记怎么躺下来了）。另外，如果phd或者postdoc做到一半想quit，后续去industry，请一定要提前准备。如果毕业后直接去应聘，那你缺乏实习经验，缺乏相关行业的素养，也缺乏人脉。如果要去业界，尽量要提前两年准备实习，多跟同样经验的人聊聊，还要多刷题。

写这些确实绝对不是让大家知难而退，我相信很多同学在小时候都‘幻想’自己能成为大学者，能当上大学教授，现在刚刚达成了第一个目标，却被前辈来了一泼冷水。这里只是想说，在学术界，任何事情都是长跑+冲刺，遇到任何挫折都要保持积极的心态。很多人不敢从事自己的兴趣，其中一个原因是，如果自己热爱的行业变成自己赖以为生的手段，会感到痛苦。如果能在小时候喜欢天文，最后（暂时）走上天文的道路，其实是一件让人羡慕，非常幸福的事情。对于未来的路，不一定需要来立下像想学一辈子天文或者组一辈子乐队这样很强的flag，在本科阶段其实能够每周读半篇感兴趣的文章，写一点代码，就慢慢往前走就好。（濮阳竣，天体物理方向，2022级本科生）
