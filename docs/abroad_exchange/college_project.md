## PSU（宾州州立大学）科研实习交换项目
The Pennsylvania State University 导师 Nikko J. Cleri

据我所知，这个项目也算是罗斌老师负责联系的。罗老师是PSU负责这个项目的W. Nielsen Brandt的学生（如果说错了欢迎指正）。不过每年提供项目的老师还是很多的，我们这一次大概有5，6个不同的项目，并且方向也很多，有黑洞，系外行星，星系等。每年具体项目都不太一样，还是自己留意通知。

我选的是Joel Leja教授的项目，但是因为还有另一个同学也选了他的项目，所以我最后做的是同一个组里的博士后Nikko提供的项目。不过鉴于教授们一般都很忙，其实博士后带的话反而也挺好的。我在那边做项目的时候基本一周可以和Nikko交流两次，一次1h，能比较详细地过一遍工作任务，遇到的问题和一些没学过的物理理论。基本上不会的都可以问，并且能在Nikko的帮助下搞明白，包括一些代码上的困难也是可以的。总之Nikko人是很nice的。

Joel的组虽然是做星系的，但是组里面每个人做的东西其实都不太一样。有做‘little red dot’的（不过好像已经去别的地方了），Nikko主要做一些和星系的光谱谱线，AGN，中心黑洞相关的，还有一些其他的但是我也不是很懂，感兴趣的可以直接查看Joel的个人网页Joel Leja。

系里也经常会有人来做报告，都会提前把通知发到学校给的邮箱里，感兴趣可以直接去，各种主题都有，能学到不少。

虽然最近美国在大家的印象里挺差的，但是PSU这边其实还挺好的。PSU在的这个城市其实就叫State College，也就是个大学城（镇，就一点点大），居民基本都是学生以及和学校相关的一些人，治安还是相对很好的（有人天天晚上十点十一点回家，不过不推荐）。另外美国的华人很多，所以和华人相关的比如中国超市（会卖一些比如酱油，大白菜等非常中式的食物，自己做饭基本没什么问题，该有的都能买到），中餐馆有很多。系里也有不少的中国留学生（不过感觉上都是疫情之前出来的，疫情之后情况确实不太好），有生活和学术上的问题都可以咨询，像问一下他们的研究领域在美国这边整体的研究情况以及全美范围内有哪些课题组之类的，还是很有帮助的。

交通方面，State college的公交很方便，用Google map就能看到时间。出去玩的话，近一点比如匹兹堡可以做bus，远一点就只能坐飞机了。但因为State college是个小地方，直飞的城市应该只有三四个，基本都要转机，美国的公共交通又基本都会晚点，所以注意留一个备选的方案，我真没招了……(葛思瑞，天体物理方向，2022级本科生)
